# DMCL branding

Concept: two chat bubbles on a 16x16 pixel grid. Green is Minecraft, indigo is Discord, the amber overlap is the bridge.

| Role | Hex |
| --- | --- |
| Ground | `#12141C` |
| Minecraft side | `#6FBF3E` |
| Discord side | `#5B63F0` |
| Bridge | `#FFC247` |
| Text / highlights | `#F4F6FA` |
| Secondary text | `#9AA3C0` |

Rules: keep the grid crisp (nearest-neighbor scaling only, never blur), no gradients or glows, wordmark is always uppercase `DMCL` in the 5x5 pixel font. Don't use Discord's or Minecraft's logos.

Assets: `branding/icon.svg`, `branding/icon-512.png` (Modrinth icon), `branding/banner.svg|png` (1280x640). All generated by `python branding/build.py`; edit that script, not the images.
